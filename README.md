# 같이 가요 (drive-together)

같이 이동하는 여러 차량이 하나의 그룹으로 묶여 서로의 위치를 내비 위에서 보고,
휴게소·경로 변경을 제안하면 **모두 동의했을 때 모든 차의 경로가 함께 바뀌는** 차량용 앱입니다.

## 기술 스택

| 영역 | 스택 |
| --- | --- |
| 차량 앱 | Android (Kotlin, Jetpack Compose), Vehicle SDK |
| 그룹 서버 | Python, FastAPI, WebSocket |

## 폴더 구조
